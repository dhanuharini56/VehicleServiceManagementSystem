# Software Requirements Specification
## Functional Requirements
- Register and view customers.
- Register vehicles linked to customers.
- Book appointments for registered vehicles.
- Save service records and calculate labour + parts cost.
- Generate bills for service records.
- Display dashboard totals.
- Analyze maintenance costs using Python.
## Non-Functional Requirements
Usable forms, persistent MySQL storage, modular code, validation, and protection of database credentials.
## Users
Service-center administrator and staff.
## Environment
JDK 17+, Maven, MySQL 8, Python 3.10+, modern browser.
