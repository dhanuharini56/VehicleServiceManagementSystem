## Abstract

The Vehicle Service Management and Maintenance Analysis System is designed to organize customer, vehicle, appointment, service and billing information in a centralized database. The system provides a browser-based user interface developed using HTML, CSS and JavaScript. It communicates with a Java Spring Boot backend through REST APIs and stores information in a MySQL database. Python and Pandas are used to analyze service records and maintenance costs. The system generates visual reports to help users understand vehicle maintenance expenses and monthly service activities. This project integrates web development, database management and data analysis concepts into a single application.
